2. 简短描述（mcmod 通常 ≤ 80–150 字）

Voidkit（无界套件）是一套面向 NeoForge / Forge / Fabric 的高版本服务端模组套件： 5 个 jar、一套代码同时支撑 1.20.1 与 1.21.1；补齐「家 / 传送 / 记分牌 / 聊天 / 经济 / 权限 / 称号 / 清扫」等通用服功能， 配套独立的反作弊与操作审计组件、加上一个轻量管理后台。玩家用原版客户端即可进服。
