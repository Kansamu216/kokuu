# 常见问题

## 玩家需要装 mod 吗？

**不需要。** Voidkit 主体是纯服务端，玩家用原版客户端即可进服。
只有 [反作弊](./../anticheat/) 的客户端 Agent 需要玩家安装（那是可选的强化项）。

## 会不会拖慢服务器 / 影响 TPS？

设计上以「不卡」为硬约束：

- 内核构造期零 IO，启动关键路径上不做文件操作；
- 周期性任务（记分牌刷新、清扫、性能采样）间隔全部可配、可关；
- 审计模块（inspector）主线程只做 O(1) 入队，重活在后台线程；
- 清扫单轮处理实体数有上限，避免一次性删几百万实体卡死主线程。

## 会不会和其它 mod 冲突？

- **零 mixin**，不抢类改写，从根上避免和整合包里已有的 mixin mod 打架。
- 命令简写**逐条容错**：名字被别的 mod 占了只会跳过这一条，其余照常注册。
- MOTD 默认**不改写** `server.properties`，不碰服主自己维护的文件。

## 命令没出现 / 没有补全？

先确认：

1. 装的是 1.21.1 对应版本（1.20.x 的 jar 不能用）；
2. `voidkit_core` 在 `mods/` 里且成功加载（看启动日志的 voidkit 行）；
3. 用 `/vk features` 确认对应功能模块是开启的；
4. 权限：没装 `voidkit_perm` 时，管理类命令需要原版 `/op`。

## 装了一半插件会不会崩？

不会。内核给每个服务都准备了兜底实现，缺哪个插件就退化成保守行为（见
[安装与部署](./install.md#少装一个会不会崩)）。

## 配置文件在哪？删存档会丢数据吗？

在**服务端根目录**的 `voidkit/`，**不在** `world/` 里。
删存档重开时，玩家档案、IP 记录、审计数据不会跟着没。

## 配置改错了怎么办？

- 所有配置都带中文注释，且内核读取时对**区间做了钳制**（例如间隔不会小于 30 秒），
  写错值通常只是被修正回安全范围，不会让服务端起不来。
- 最坏情况删掉对应的配置文件，重启会自动按默认值重新生成。

## 支持 Fabric / 1.20.x 吗？

套件的 `core.platform` 适配层就是为跨加载器/跨版本准备的，
规划支持 **NeoForge + Fabric，1.20.X–1.21.X**。
当前主线是 **NeoForge 1.21.1**；移植进度见仓库 `ROADMAP.md`。

## 反作弊能做到什么、做不到什么？

见 [反作弊模块](../anticheat/) 的「威胁模型边界」一节 —— 我们不夸大能力：
它能赶走「装个透视就进服」的绝大多数人，但防不住内核级对手（那需要驱动签名，
与「零 mixin」冲突，明确不做）。

## 有 API 吗？能二次开发吗？

有。插件通过 `core.api` 包提供的稳定契约开发，见 [开发指南](../dev/)。
