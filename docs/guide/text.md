# 文本语法

MOTD / TAB / 记分牌 / 聊天栏 / 公告 / 菜单里只要是文本，都支持同一套语法。

## 颜色与样式（legacy 颜色码）

用 `&` 加一个字符：

```
&0黑  &1深蓝 &2深绿 &3深青 &4深红 &5深紫 &6金  &7灰
&8深灰 &9蓝  &a绿  &b青  &c红  &d粉  &e黄  &f白
&l粗体  &o斜体  &n下划线  &m删除线  &k随机字  &r重置
```

例：`&8[&6%group%&8] &b{name} &8» &f{message}`

> 记分牌的行不支持点击事件，里面写 `[文字](run:/命令)` 只会显示成普通文字。

## 变量（占位符）

模板里写 `%变量名%`，解析时替换成实际值。**写错的变量会原样保留**，方便你一眼看出打错了哪个。

常用变量：

| 变量 | 含义 | 变量 | 含义 |
|---|---|---|---|
| `%player%` | 玩家名 | `%world%` | 所在世界（可在 `worldNames` 配中文） |
| `%online%` / `%max%` | 在线人数 / 上限 | `%tps%` | 服务器 TPS |
| `%group%` | 权限组名 | `%prefix%` | 组前缀（带颜色） |
| `%title%` | 称号（需 `voidkit_display`） | `%level%` | 经验等级 |
| `%playtime%` | 在线时长 | `%ping%` | 延迟（ms） |
| `%health%` / `%max_health%` | 当前 / 最大血量 | `%food%` | 饱食度 |
| `%x%` `%y%` `%z%` | 坐标 | `%homes%` | 家的数量 |
| `%date%` / `%time%` | 日期 / 时间 | `%uptime%` | 开服时长 |
| `%uuid%` | 玩家 UUID | | |

完整清单随时用 `/vk placeholders` 查看。

## 可点击文本

```
[显示的\文字](动作 "悬停说明")
```

| 动作 | 点击后 |
|---|---|
| `run:/spawn` | **以玩家身份直接执行**命令 |
| `suggest:/msg ` | 把命令填进聊天框，自己回车再发 |
| `url:https://…` | 打开链接 |
| `copy:文本` | 复制到剪贴板 |

例：TAB 底栏放一排按钮

```jsonc
"footer": [
  "&8[&a回城&8](run:/spawn \"&7点一下回到出生点\")  &8[&b主菜单&8](run:/menu)"
]
```

⚠️ **支持点击的范围**：

| 位置 | 可点击 |
|---|---|
| 聊天栏 | ✅ |
| TAB 顶 / 底栏 | ✅ |
| 记分牌 | ❌ 原版协议限制（行是纯字符串） |
| MOTD | ❌ 服务器列表不接受点击事件 |

## 聊天栏里的特殊 token

聊天格式（`display/chat.json` 的 `format`）另有两个专用 token：

| token | 含义 |
|---|---|
| `{name}` | 玩家名（会自动挂上悬停浮层与点击动作） |
| `{message}` | 玩家说的话 |

```jsonc
"format": "&8[&6%group%&8]&7[&aLv%level%&7] %title%&b{name} &8» &f{message}"
```

有 `colorPermission` 的玩家可以在自己的 `{message}` 里用 `&` 颜色码。
