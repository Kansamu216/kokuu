# Voidkit 使用文档

> NeoForge 1.21.1 纯服务端基础模组套件。玩家用**原版客户端**即可进服。
> 本文档面向服主/管理员：装什么、有什么指令、权限节点怎么配、配置文件每一项是什么意思。

- 版本：v1.2.0 ｜ 构建：`./build.sh build`（需 JDK 21）｜ 产物在各自 `build/libs/`
- 安装：把要用的 jar 丢进服务端 `mods/`，**最少装 `voidkit_core`**，其余按需
- 内核管理命令是 **`/kcore`**（旧文档写的 `/voidkit` 已不再注册）

| jar | modId | 内容 | 不装的后果 |
|---|---|---|---|
| `core` | `voidkit_core` | 内核：模块开关 / 数据存储 / 变量 / 多语言 / 玩家追踪 | —— 必装 |
| `essentials` | `voidkit_essentials` | 家 / 传送点 / 出生点 / TPA / back / 管理工具 / 命令简写 / 信息查询 | 家上限退化成保守默认（3 / 32） |
| `display` | `voidkit_display` | MOTD / TAB / 记分牌 / 聊天栏 / 公告 / 菜单 | 相应展示全关 |
| `perm` | `voidkit_perm` | LuckPerms 风格权限 | 权限判定退化成「只认原版 OP」 |
| `title` | `voidkit_title` | 称号 + 游戏内 GUI | 称号功能不可用 |
| `economy` | `voidkit_economy` | 货币 / 转账 / 排行 / 估值表 | 扣款恒失败（表现为「暂时不能购买」） |
| `utility` | `voidkit_utility` | 定时清扫 + 垃圾桶 + 性能监测 | 无清扫 / 无 /perf |
| `web` | `voidkit_web` | 管理 API 桥（唯一监听端口的模块） | 服务器不开任何端口 |

**jar 粒度 ≠ 功能粒度**：每个功能都是独立 Feature，可在 `core/config.json` 的 `features` 段、`/kcore features` 或面板里逐个开关。模块 id 全集见 [3.9 内核命令](#39-内核内核-core)。

## 1. 运行时目录

首次启动在**服务端根目录**（不是存档里，删存档不丢玩家数据）生成：

```
voidkit/
├── core/
│   ├── config.json          内核：语言 / 模块开关 / IP 记录 / 落盘间隔
│   └── data/                玩家档案、上下线日志
├── display/
│   ├── motd.json            MOTD（多套轮换）
│   ├── tab.json             TAB 顶栏 / 底栏
│   ├── scoreboard.json      记分牌（可按权限切换多套）
│   ├── chat.json            聊天格式、悬停浮层、点击动作
│   ├── announce.json        公告框线 / 通道 / 轮播
│   └── menu.json            菜单与物品绑定
├── perm/
│   ├── groups.json          权限组树
│   ├── users.json           玩家级覆盖
│   └── settings.json        全局设置
├── title/
│   └── titles.json          称号定义
├── essentials/
│   ├── config.json          家上限 / TPA / back / 传送冷却
│   └── commands.json        要停用的命令简写
├── economy/
│   ├── config.json          货币名 / 初始余额 / 手续费
│   ├── values.json          物品估值表（/sell /value 用）
│   └── accounts.json        账户余额（运行时数据，别手改）
├── utility/
│   ├── clearlag.json        清扫间隔 / 通道 / 垃圾桶规则
│   └── perf.json            TPS·MSPT 阈值 / 区块热点 / 干预开关
└── web/
    └── config.json          管理 API 监听地址与令牌
```

所有配置都是 **JSONC**：带中文注释，读取时自动剥注释。手改只改值，注释可以留着。

## 2. 权限系统（voidkit_perm）

### 2.1 判定规则

优先级从高到低：

1. **玩家自己的节点**（`users.json`，含临时权限）> 组的节点
2. **否定优先**：`-voidkit.command.fly` 明确禁止，压过所有组的肯定节点
3. **通配**（`wildcardEnabled: true` 时）：`*` = 一切；`voidkit.home.*` 前缀通配命中 `voidkit.home.set`
4. 组支持**继承**（`parents`，可多级），权限与前缀都继承；`weight` 数值越大越优先
5. 谁都没命中 → 看 `settings.json` 的 `defaultValue`（**默认 false = 没有权限**）

**管理员判定**（`/perm` 管理、`/setwarp`、`/invsee` 等所有 admin 检查）：
`opBypass: true`（默认）时**原版 OP（等级 ≥2）直接放行**；或拥有 `voidkit.admin` 节点。
想完全靠权限系统管理就设 `opBypass: false`。

**前缀显示**：`prefixFromHighestWeight: true`（默认）= 取权重最高组的前缀；false = 始终用主组。

### 2.2 内置组（首次启动自动生成）

| 组 | 前缀 | 权重 | 节点 | 说明 |
|---|---|---|---|---|
| `default` | `&7` | 0 | `voidkit.command.spawn` `voidkit.command.home` `voidkit.command.tpa` `voidkit.command.back` | 未分组玩家自动归入 |
| `vip` | `&6[VIP]&r` | 10 | `voidkit.homes.limit.10`（继承 default） | 家上限提到 10 |
| `admin` | `&c[管理]&r` | 100 | `*`（全部权限） | 系统级组，缺失自动补回 |

> ⚠️ 注意：`voidkit.command.*` 这四个节点目前只是**预留给默认组的约定节点**，
> `/home /tpa /spawn /back` 命令本身只要求「是玩家」，删掉节点不会挡住命令。

### 2.4 /perm 指令（游戏内点击式编辑）

```
/perm                                  我的权限概览
/perm check <节点>                      检查某节点（输出"为什么"）
/perm nodes                            列出我生效的全部节点
/perm user <玩家>                       查看玩家
/perm user <玩家> group <组>            设主组
/perm user <玩家> addgroup <组>         加附加组
/perm user <玩家> delgroup <组>         移除附加组
/perm user <玩家> add <节点>            加节点（前缀 - 就是否定）
/perm user <玩家> del <节点>            删节点
/perm user <玩家> grant <节点> <分钟>    临时授权（到期自动失效）
/perm group                            列出全部组
/perm group <组>                        查看某组（含继承链）
/perm group <组> add|del <节点>         增删节点
/perm group <组> parent <父组>          加父组（继承）
/perm group <组> unparent <父组>        移除父组
/perm group <组> prefix|suffix <文本>   设前后缀（支持 & 颜色码）
/perm group <组> weight <数值>          设权重
/perm create <组> / /perm delete <组>   新建 / 删除组（默认组不可删）
/perm reload                           从磁盘重载
```

除查看类（`/perm`、`check`、`nodes`、`help`）外都需要管理员权限。输出里的 `[xxx]` 是可点击按钮，点一下直接执行或填进聊天框。组一变，TAB / 聊天前缀会自动刷新。

图例：`[管理员]` = 需 OP 或 `voidkit.admin`；`[节点]` = 需对应权限节点。

## 4. 文本语法（MOTD / TAB / 记分牌 / 聊天 / 公告 / 菜单 通用）

```
&a &l              颜色与样式（legacy 颜色码）
%player% %online%  变量（完整清单游戏内 /kcore placeholders）
[文字](动作 "悬停") 可点击文字
```

| 动作 | 点击后 |
|---|---|
| `run:/spawn` | 以玩家身份执行命令 |
| `suggest:/msg ` | 填进聊天框，自己回车 |
| `url:https://…` | 打开链接 |
| `copy:文本` | 复制 |

⚠️ **点击支持范围**：聊天栏 ✓、TAB ✓、**记分牌 ✗、MOTD ✗**（原版协议限制）。

常用变量：`%player% %online% %max% %tps% %ping% %world% %date% %time% %group% %prefix% %playtime% %level% %health% %x% %y% %z%`。

## 5. 配置文件详解

> 每个字段都列：默认值 ｜ 说明。改完生效方式见 §5.11 速查表。

### 5.1 voidkit/core/config.json

| 字段 | 默认 | 说明 |
|---|---|---|
| `language` | `"zh_cn"` | 界面语言：`zh_cn` / `en_us`。词表在 `voidkit/lang/en_us.json`，可自行改 |
| `features` | `{}` | 模块开关。键是模块 id，false = 停用；没写的用模块默认值 |
| `recordIps` | `true` | 是否记录玩家 IP 历史 |
| `maxJoinLogEntries` | `20000` | 上下线日志最多保留条数（JSONL 滚动） |
| `autoSaveSeconds` | `300` | 玩家档案自动落盘间隔（秒），数据本身是写时即落，这只是兜底 |

可用的 feature id：`core` `player-tracking` `motd` `tab` `scoreboard` `chat-format` `announce` `menu` `permissions` `titles` `homes` `tpa` `back` `teleport` `spawn` `warps` `info` `admin-tools` `command-alias` `economy` `clearlag` `perf` `remote-api`。

### 5.2 voidkit/essentials/config.json

| 字段 | 默认 | 说明 |
|---|---|---|
| `defaultHomeLimit` | `3` | 默认家数；组可用 `voidkit.homes.limit.<n>` 覆盖 |
| `maxHomes` | `32` | 家数硬上限（防止给某个组配天文数字） |
| `tpaEnabled` | `true` | 是否允许 TPA 系命令 |
| `tpaTimeoutSeconds` | `60` | 请求有效期（10~3600） |
| `backEnabled` | `true` | 是否允许 /back |
| `teleportCooldownSeconds` | `0` | 两次传送间冷却（秒），0 = 不限 |

### 5.3 voidkit/essentials/commands.json

| 字段 | 默认 | 说明 |
|---|---|---|
| `disabled` | `[]` | 要停用的简写名（不含斜杠），如 `["day","sun"]`。别的 mod 抢了同名命令、且你想用对方的版本时写这里。可用名：`day night noon midnight dawn dusk freeze unfreeze sun rain thunder gr diff gm` |

### 5.4 voidkit/display/*.json

**motd.json**：`enabled`(`true`)、`updateSeconds`(`5`，重新推送间隔)、`rotation`(`fixed`/`order`/`random`)、`writeServerProperties`(`false`，默认不碰 server.properties)、`variants[]`：每套 `lines`（最多两行，原版限制）+ `weight`（random 模式权重）。

**tab.json**：`enabled`、`updateSeconds`(`5`)、`header[]` / `footer[]`（多行文本，支持变量与点击）、`useGroupPrefix`(`true`，TAB 名字上显示组前后缀，走原版队伍机制)。

**scoreboard.json**：`enabled`、`updateSeconds`(`2`)、`boards[]`：`id`、`title`、`lines[]`（最多 15 行）、`permission`（留空人人可见）、`priority`（越大越优先；玩家看到「有权限的里面优先级最高」那套）。

**chat.json**：

| 字段 | 默认 | 说明 |
|---|---|---|
| `format` | `"%prefix%&f{name} &8» &f{message}"` | 聊天模板，可用 `{name} {message} {world}` 与 %变量% |
| `colorEnabled` / `colorPermission` | `true` / `voidkit.chat.color` | 允许聊天用颜色码 |
| `placeholderPermission` | `voidkit.chat.placeholder` | 允许聊天用变量 |
| `blockMuted` | `true` | 禁言玩家发言直接拦下 |
| `nameHoverEnabled` / `nameHover[]` | `true` / 默认 6 行 | 名字悬停浮层（文字，不能放头像） |
| `nameClick` | `run:/tpa {name}` | 点名字执行什么；怕误触改 `suggest:/msg {name}`，留空不可点 |

**announce.json**：`enabled`、`channel`(`chat`/`actionbar`/`both`/`off`)、`prefix`(`"&6[公告] &r"`)、`header[]`/`footer[]`（框线）、`sound`（默认铃声，留空不播）、`auto`：`enabled`(`false`)、`intervalSeconds`(`600`，下限 30)、`random`(`true`)、`channel`、`messages[]`。

**menu.json**：

```
settings: closeOnAction(true) / openSound
menus:  菜单名 -> { title, rows(1~6), items: { "槽位号0~53": 按钮 } }
按钮:   icon(物品id) / name / lore[] / amount / permission /
        action: run:/命令 | console:/命令 | menu:另一菜单 | back | close |
                url:… | copy:… | suggest:…
openers: 物品id -> { menu, name, lore[], permission }   手持右键开菜单
```

console: 动作绕过玩家权限，只用于可信菜单。url/copy/suggest 点击槽位时无法立即生效，会退化成聊天提示。

### 5.5 voidkit/perm/settings.json

| 字段 | 默认 | 说明 |

| `opBypass` | `true` | 原版 OP(≥2) 放行一切检查 |

## 6. 垃圾桶机制要点

- 清扫**默认不是删除而是进桶**，玩家可在下一轮清扫前 `/trash` 取回
- 桶内**按物品类型聚合**（1 万圆石 = 1 格），内存与掉落物总量无关 —— 不会因掉落物太多崩服
- 桶满按**价值分**淘汰：`protectedItems` 与改过名的永不动 → `trashItems` 优先淘汰 → 其它按稀有度/附魔累加
- 经验球/箭直接删除（不是物品，无法原样归还）
- 单轮处理量有上限（`maxPerSweep`），异常刷量时分轮消化，不卡主线程

## 7. 常见问题

- **命令被别的 mod 抢了**：简写命令逐条容错，撞名只跳过那一条；要主动让位用 `essentials/commands.json`
- **清扫播报看不到**：检查 `clearlag.json` 的 `announceChannel` 是否被改成了 off
- **权限改了不生效**：`/perm reload`；组变更会自动刷新 TAB/聊天前缀
- **MOTD 想要点击按钮**：做不到，服务器列表是原版协议限制；把入口放 TAB 底栏
- **配置里字段没注释**：极少数新字段（如 perf 的 `interveneMaxPerRun`）尚未进注释表，字段本身有效

## 8. 已知注意点

- `/fly /god /heal /feed` **对自己使用没有权限门槛**（任何玩家可用，对他人使用才要管理员）。生存服如果不想让玩家飞，要么在 `features` 里关掉 `admin-tools`，要么用 `/perm user` 给玩家加 `-voidkit.admin` 之外的方案 —— 当前版本没有独立的 fly 节点，建议关注后续版本增加 `voidkit.command.fly` 等节点
- `voidkit.command.spawn/home/tpa/back` 四个节点目前只是默认组里的约定节点，命令本身未强制检查（见 §2.2）
- 数据安全：`voidkit/` 目录在服务端根目录，**备份时连同 world 一起备份它**；`accounts.json`、`core/data/` 是运行时数据，不要手改
